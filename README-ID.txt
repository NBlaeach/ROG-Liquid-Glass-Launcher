ROG Liquid Glass Launcher — proyek sumber awal (tanpa iklan)

Fitur:
- Launcher Android sederhana, tanpa SDK iklan atau koneksi internet.
- Jam dan tanggal.
- Grid aplikasi otomatis memakai ikon aplikasi yang sudah terpasang.
- Dock transparan sederhana.
- Tampilan gradasi biru ala Liquid Glass.

Catatan:
- Ini proyek sumber Android, BUKAN APK siap instal.
- Build menggunakan Android Studio dengan Android Gradle Plugin 8.6.1, Kotlin 2.0.20, JDK 17, dan Android SDK 35.
- Buka folder proyek di Android Studio, tunggu Gradle Sync, lalu Build > Build APK(s).
- APK debug akan berada di app/build/outputs/apk/debug/app-debug.apk.
- Setelah instal, pilih "ROG Liquid Glass Launcher" sebagai aplikasi Home/default.
- Launcher ini versi awal: belum memiliki widget interaktif, pengaturan tema, atau wallpaper bawaan.
- Tidak perlu root, unlock bootloader, atau flash recovery.
